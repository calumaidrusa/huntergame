## 2026-07-03 · 盤點現況，定下「發音是教學核心、任何音訊都不能蓋過它」的第一原則

我接手時遊戲完全沒有 BGM、沒有音效，只有詞彙發音（klokah.tw 真人母語者錄音，1092 筆全涵蓋）。我意識到這個專案的音訊設計跟一般遊戲不一樣——詞彙發音不是配角，是**教學核心**，我規劃的所有東西都要以「不干擾發音」為前提。我定了幾條給自己（也給小工程接線時）的原則：BGM 音量要低（建議 ≤0.2）、詞彙發音播放時考慮 ducking（自動降低 BGM）、音效要短促不能延遲或蓋住發音、聽聲辨字模式下 BGM 要更低甚至暫停。

同一時間我也把音樂層面的文化安全定調：絕不取用或模仿太魯閣族的祭儀歌謠（有神聖性，不是配樂素材），口簧琴這類重要傳統樂器也不隨意採樣當「原住民風」裝飾——不確定就不用，安全路線是走通用的山林/冒險情境音樂。

## 2026-07-03～04 · 12 類音效 + 雙 BGM + ducking

我用 Web Audio API 直接合成了 12 類音效（射箭、命中、答錯、combo 遞增、過關小旋律、Game Over 三音符下行、解鎖上行閃亮音、按鈕點擊等），零成本零授權問題，而且合成音效的復古感剛好契合這種 arcade 打字遊戲的調性。BGM 做了標題/遊戲兩首，接上了發音 ducking——詞彙發音播放時自動壓低 BGM 音量，播完再回升，確保教學內容永遠是最清楚的聲音。

## 2026-07-05 · 把遊戲 BGM 從旋律曲換成無旋律環境 pad

原本的遊戲 BGM 是有旋律的 loop，我後來評估後改成無旋律的環境音 pad（`game-ambient.wav`，`make_ambient_pad.py` 合成、可調參數），原因是旋律型 BGM 的頻譜比較容易跟語音發音的清晰頻段打架，環境音 pad 刻意避開那個頻段，對「聽清楚發音」這件教學核心更友善。同一輪我也把 BGM 音量從 0.15 微調到 0.10，進一步確保不會搶戲。

交棒：素材對應表跟授權紀錄我有持續維護（哪個音檔來源是哪裡、授權條款是什麼），這是教學場景要乾淨授權的基本要求，之後如果要再加音效/BGM，記得比照這個習慣記錄來源。木雕喇叭按鈕的視覺是小畫家做的，播放行為的接線是小工程的事，我這邊只負責音訊素材本身跟音量/ducking 的方案設計，沒有跨界去改 UI 或 JS 接線邏輯。

## 2026-07-07 · 遊戲 BGM 換成使用者指定的 Suno 曲，音量再降

使用者給了一個 Suno 分享連結，要把遊戲 BGM 換成那首、而且要更小聲。我從 share 頁的 HTML 裡撈到 CDN mp3（`cdn1.suno.ai/95f4a9d5-....mp3`，注意頁面裡還有一個 `sil-100.mp3` 是靜音佔位別抓錯），metadata 顯示曲名「Moss Arrow Loop」、150.9s、Suno v4.5。抓下來 3.68MB，放成中性檔名 `game-bgm-suno.mp3`，把 `#gameBgm` 的 src 換過去。標題環境音沒動——使用者只要換遊戲中 BGM，標題畫面又不出題、沒搶發音問題。

音量這次降得比上次更明顯：normal 0.10→0.05、duck 0.06→0.025。有意識的判斷：這首是**有旋律的管弦樂**，正好跟我 07-05 那輪「把旋律曲換成無旋律環境 pad 以避開語音頻段」的方向相反。但使用者明確指定要這首，我尊重，改用**更低音量**來補償——維持「發音永遠最清楚」這條第一原則不變。旋律型 BGM 在低音量下反而更能當純襯底。

兩件事要記著、也寫進了 audio_wiring.md 給主管拍板：①這首是 **AI 生成（Suno）、非 CC0**，跟我以往堅持的素材庫公有領域授權不一樣——Suno 生成內容的商用權利歸使用者的訂閱方案，授權責任在使用者，正式對外發布前要請使用者確認方案允許。這是我第一次在這專案用非 CC0 的音樂，破例是因為「使用者自己生成、自己指定」，但我還是照規矩把授權性質據實標清楚，沒有假裝它是乾淨的公有領域素材。②檔案 3.68MB 略超 1–3MB 建議上限，本環境沒 ffmpeg 沒法重編碼壓縮，先照舊（title-ambience 本來也 3.43MB），要壓得等有 ffmpeg 的機器。

還有個環境上的坑值得記：我的 worktree（lucid-newton）是從 main 拉的舊基底，根本沒有 BGM 系統——BGM/BgmManager/音量常數/bgm 目錄全都只在 `feat/v2-overhaul-accounts-ui-vocab` 分支，而那個分支正 checkout 在主專案根目錄。所以我是直接在主專案根目錄（feat 分支的活躍工作區）動的，不是在自己的 worktree。下一個接手的我，如果又被派 BGM/音效的活，先 `git worktree list` 看 BGM 系統在哪個工作區，別在沒有 BGM 的 worktree 裡瞎改。舊的 `game-loop.mp3`（CC0 Town Theme）現在變孤兒檔沒人引用，留著無害，沒刪。
