# 族語射手 — 太魯閣族文化安全準則

> 給所有 agent（小工程 / 小排版 / 小蘋果 / 小歌手，以及餵給 Codex 的生圖工作單）與人類協作者共用的工作準則。
> 由小畫家依實際審查案例整理，權威版放在 `harness/` 與 `LESSONS.md` 同層。
> 這份是可執行的避雷清單，不是文化教材——照著做就能避開最常見的挪用地雷。

---

## 0. 適用範圍（先讀這一句）

**本準則適用於「族語射手 TRUKU WORD ARCHER」所有對外素材，不只生圖。**
美術、UI 元件、音樂/音效、文案標語、示意圖、簡報、對外貼文——只要會被玩家或大眾看到/聽到，都要過這份準則。生圖只是最常踩雷的地方，不是唯一。

---

## 1. 核心原則

1. **採「通用奇幻 / 叢林探險」視覺語彙，不採任何特定原住民族群的文化符號。**
   我們要的是「任何一款山林狩獵主題手遊都會有」的通用美術：木雕金邊、羊皮紙卷軸、藤蔓綠葉、峽谷森林地景、通用奇幻弓箭手。這些沒有族群歸屬，安全。
2. **不挪用、不混用任何特定族群的文化符號。** 太魯閣族的、泰雅族的、阿美族的、排灣族的、美洲原住民的——一律不套用。即使是「致敬」也不行，因為 AI 生圖與非專業手繪幾乎必然畫錯、畫混、畫成刻板印象。
3. **人物一律不畫特定族群裝束。** 遊戲裡的獵人角色維持「泛遊戲奇幻弓箭手 / 遊俠」通用造型（頭帶、護臂、素色背心/短衣、箭袋）。可以有清楚五官與動態姿勢，但**不得**加上任何試圖模仿真實太魯閣族服飾紋樣、織品圖案、紋面的細節。
4. **不確定就省略，絕不編造。** 拿不準某個圖紋/服制/儀式細節是否正確、是否敏感時，直接不畫，換成中性通用元素。寧可平淡也不要挪用或杜撰。
5. **這是一款教育向、對真實族群負責的產品。** 太魯閣族 2004 年才正名為獨立族群，把它跟泰雅族或其他族混為一談本身就是傷害。用字避免 `tribal`、`primitive`、`native jungle tribe` 等泛化獵奇字眼，正式稱呼為 **太魯閣族（Truku / Seediq Truku）**。

---

## 2. 明確禁用清單（＋為什麼敏感）

以下元素**一律不得**出現在任何素材中。每條附上為什麼，讓你自己遇到新狀況時能舉一反三。

| 禁用元素 | 為什麼敏感 |
|---|---|
| **菱形織紋 / 連續菱形織帶 / 連續幾何織帶** | 這是泰雅族・太魯閣族的傳統織紋，俗稱「**祖靈之眼**」，是有神聖意涵的文化符號，不是裝飾花邊。**這是 AI 生圖最常自動填上的圖案**——木雕表面、圓形徽章邊框、旗面、木牌，AI 動不動就給你鋪一圈菱形織帶。關卡圖示那次 mockup 的 LEVEL4 就是一顆紅色菱形圖騰，被擋下改成中性版。**這是本準則的頭號地雷，所有木質/圓框/織面素材都要主動防這一條。** |
| **紋面（Ptasan）** | 太魯閣族／賽德克族的紋面是標誌成年與技能成就（男性狩獵、女性織布）的**極度神聖且敏感**的文化符號，不是化妝或塗鴉。**不得在任何角色臉上描繪**，即使風格是寫實細緻的 RPG 畫風、畫得出清楚五官，臉上也必須乾淨無紋。 |
| **祖靈眼 / 眼形織紋母題（ancestral-eye motif）** | 同上，菱形織紋的核心意象就是「眼」。任何「眼睛狀」的重複幾何母題填在器物/織面上都要避開。 |
| **羽冠 / 戰紋 / 圖騰柱 / 捕夢網** | 這些是**美洲原住民**元素，跟台灣原住民毫無關係。AI 一聽到 "native / tribal / hunter" 很愛亂加，是典型的「泛原住民刻板印象」混用，必須明確排除。 |
| **泰雅族菱形紋 / 織紋圖案** | 太魯閣族與泰雅族歷史同源，但 2004 年後是官方認定的**不同族群**，不能混為一談。泰雅的菱形紋不等於可以拿來代表太魯閣。 |
| **阿美族元素**：紅黑配色、'alofo 情人袋、八角星十字繡 | 阿美族的視覺事實，套到太魯閣族身上就是跨族群混用——這正是我們參考的阿美族守則本身警告的錯誤。 |
| **排灣族元素**：琉璃珠、百步蛇紋、貴族階級圖騰 | 排灣族專屬文化符號，與太魯閣族無關。 |
| **奇幻「部落戰士」皮甲 / 暴露服裝 / 骨飾獠牙** | 這是遊戲業界的「野蠻人部落」刻板印象，把原住民野蠻化/獵奇化，教育產品絕不採用。 |
| **自行發明的紋面圖案、階級標記、儀式細節** | 杜撰文化細節比留白更糟——它會被誤認為真實族群知識而流傳。不確定就省略。 |

## 3. 安全替代做法（該用什麼取代）

想要「有質感、有裝飾細節」又不踩雷，用這些中性通用元素：

- **孤立的金鉚釘 / 寶石 / 圓釘裝飾**（點狀、分散、非連續）——取代連續織帶。這是我們一路在用的安全裝飾語言：四角各釘一顆金鉚釘 ≠ 沿邊鋪一圈菱形織紋。**關鍵差異是「孤立點狀」vs「連續帶狀重複幾何」**，前者安全，後者就是織紋地雷。
- **素面木紋 / 低調木雕底紋**——原木質感、年輪、簡單刻痕，不帶任何具族群意涵的重複幾何母題。
- **通用藤蔓 / 綠葉 / 卷草裝飾**——自然植物紋樣沒有族群歸屬，安全，也符合叢林探險主題。
- **暖色木雕 + 金邊**——遊戲既有的木雕工藝視覺語言（懸掛木牌、雕花邊角、金色描邊），這是產品的裝飾主調。
- **羊皮紙 / 卷軸材質**——做舊邊緣、卷軸捲曲，通用冒險主題語彙。
- **峽谷 / 溪流 / 森林等自然地景**——地理景觀本身無挪用疑慮（見第 6 節升級條款）。
- **通用奇幻弓箭手造型**（人物）——頭帶、護臂、素色短衣/背心、箭袋、弓，任何奇幻遊戲都有的裝備，臉部乾淨無紋。
- **中性功能符號**（勾/叉/播放/放大鏡/準星/沙漏等）——UI icon 用純幾何符號，不帶文化母題。

> 判斷口訣：**「這個元素換到一款完全無關的西方奇幻或通用手遊裡，會不會顯得突兀？」** 不突兀 → 通用安全；一看就「這是某原住民族的東西」→ 停下來審查。

## 4. 可直接複用的 Negative Prompt 字串（給 Codex / 生圖）

**每一張生圖工作單都掛上這串，低風險素材也照掛（木質/圓框/旗面最易被 AI 自動填織紋，主動防呆）：**

```
no woven diamond pattern, no continuous woven bands, no ancestral-eye motif,
no facial tattoo, no Ptasan, no tribal tattoo, no Atayal motif, no Amis motif,
no Paiwan motif, no Native American motifs, no totem pole, no feather headdress,
no dreamcatcher, no war paint, no tribal warrior armor, no ethnic textile pattern,
no repeating geometric border, no human character wearing indigenous clothing,
no invented ritual symbols, no text, no watermark
```

**若素材本就不該有人物**（純 UI 元件、器物、背景），再加：
```
no human character, no face
```

**若是服飾/器物類詞彙插畫**（pala 布裙、towkan 背網、habuk 腰帶等），加：
```
object only, no person wearing it, no model, plain neutral background
```

> 說明：`no woven diamond pattern` / `no ancestral-eye motif` / `no continuous woven bands` 三條專打頭號地雷（第 2 節菱形織紋）；`no facial tattoo` / `no Ptasan` 打紋面；後面一整串打各族與美洲原住民混用。這串是累積多次生圖（關卡圖示紅菱形、進度條旗幟、圓木徽章 icon、Enter 鍵帽）驗證下來的標準防呆組合。

## 5. 出圖 / 接素材前的審查檢查清單

**任何涉及人物、服飾、器物、儀式、聚落場景的素材**，生成前 / 接進畫面前逐項打勾：

- [ ] **織紋**：木質面、圓形徽章邊框、旗面、木牌、卡片邊框上，有沒有被畫上連續菱形/幾何織帶？（＝祖靈之眼地雷，最常見）
- [ ] **紋面**：任何角色臉上有沒有線條/圖案？（必須乾淨無紋）
- [ ] **人物裝束**：角色是不是停在「通用奇幻弓箭手」造型？有沒有混進疑似某族群的服飾/配件/圖案？
- [ ] **跨族群混用**：有沒有羽冠、圖騰柱、捕夢網（美洲）、紅黑配色/情人袋（阿美）、琉璃珠/百步蛇（排灣）等其他族群元素？
- [ ] **杜撰**：有沒有看起來「像某種文化符號」但其實是 AI 編出來、我也說不清出處的圖案？（有 → 拿掉）
- [ ] **器物/服飾詞彙**：pala、towkan、habuk、nuqih、bhniq、pucing 等傳統器物詞，是不是只畫物件本體、沒畫人物穿戴？（優先畫物件是最安全做法）
- [ ] **negative prompt**：第 4 節那串有沒有掛上？（生圖工作單專用）
- [ ] **夾帶文字**：圖裡有沒有被 AI 加上不該有的文字/浮水印/拼錯的字？
- [ ] **用字**：prompt / 文案有沒有出現 tribal / primitive / native jungle tribe 等泛化獵奇字眼？（改用中性描述或正確稱呼 Truku）

任一項不通過 → 退回重生 / 改設計 / 拿掉該元素，通過才交下一棒（小排版換圖、小工程接邏輯）。

## 6. 升級條款

- **正式出版、教學教材、對外公開發布**（非遊戲內臨時素材）前，本準則只是「避免明顯挪用」的底線，**不等於文化正確性背書**。這類用途建議**請太魯閣族文化工作者/顧問確認**後再定稿。AI 生成的圖案為近似視覺語彙，非特定部落或年齡階級服制的精確復刻。
- **地理景觀**（太魯閣峽谷、立霧溪、山林森林等）本身**無文化挪用疑慮**，可放心作為背景主題——但仍建議另案審查：①不要把其他地區/國家的地標混進「太魯閣」場景；②不要在自然地景上疊加任何族群圖騰或杜撰的「部落聚落」細節。
- **紋面（Ptasan）等敏感符號**若因特殊教育理由確有需要呈現，**必須經人類主管與族群顧問雙重確認**，不得由 agent 自行決定描繪。

## 附：四段式審查回報格式（涉文化素材時對主管/使用者的回報）

當某素材涉及人物/服飾/器物/場景，用這個格式回報，讓決策者一眼看懂風險與處置：

```

建議 Prompt：[已含第 4 節 negative、校正後的完整 prompt]
備註：AI 生成圖案為近似視覺語彙，非特定部落/年齡階級服制的精確復刻。若用於正式出版、教學或對外公開，建議請太魯閣族文化工作者確認。
```
